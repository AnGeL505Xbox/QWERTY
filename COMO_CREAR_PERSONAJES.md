# Crear personajes
`data/content.json` contiene `characters`: `id`, `name`, `health`. Por ahora se utiliza la primera entrada y la interfaz muestra Lira. Para cambiar a la protagonista modifica esos datos y los textos en `scenes/main.gd`.

Añadir una entrada aún no crea un equipo: selección, mazos individuales y equipo de hasta tres integrantes pertenecen a la fase 3. No dupliques el motor de combate para cada personaje.
