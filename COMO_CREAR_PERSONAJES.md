# Crear personajes
`data/content.json` contiene `characters`: `id`, `name`, `health`. Por ahora se utiliza la primera entrada y la interfaz toma su nombre de los datos. Para cambiar a la protagonista modifica esos datos; el sprite se configura por separado.

Añadir una entrada aún no crea un equipo: selección, mazos individuales y equipo de hasta tres integrantes pertenecen a la fase 3. No dupliques el motor de combate para cada personaje.
